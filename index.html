03 / How I work

Four phases, no surprises.

Every engagement runs the same way, so teams always know what is happening and what comes next.

01
Discover

Understand the problem space, requirements and competitive context, then set objectives, deliverables and timelines.

02
Define

Shape information architecture, journeys and user flows. Build the design language and clickable prototypes for feedback.

03
Design

High-fidelity UI, interaction design, design systems and prototypes, documented so engineering never has to guess.

04
Deliver

Accessibility review, developer handoff and implementation collaboration, plus revisions once real users are in.
